# MysteryDungeonPet

**[직접 수정 안내서 — 컷신 시간·텍스트·동작·이동 경로·빌드 방법](QUICK_EDIT_GUIDE.md)**

대분류·소분류 목차에서 원하는 항목을 골라 파일 위치와 검색어로 바로 찾는다.

현재 실행 코드와 루트 EXE는 [work 브랜치](https://github.com/ahntaeyoung80-coder/MysteryDungeonPet/tree/work)에 있다. GitHub Desktop에서 work를 pull한 뒤 MysteryDungeonPet.exe를 실행한다. [최신 상태](https://github.com/ahntaeyoung80-coder/MysteryDungeonPet/blob/work/PROJECT_STATE.md)와 [Windows 실행 안내](https://github.com/ahntaeyoung80-coder/MysteryDungeonPet/blob/work/docs/WINDOWS_QUICKSTART.md)를 따른다.

『포켓몬 불가사의 던전: 하늘의 탐험대』의 데이터와 리소스를 재활용하는 Windows용 초경량 데스크톱 펫 프로젝트.
원작 동작·출현 분포를 우선하며, 던전은 시작방·이동방·계단방의 2~3개 방으로 단순화한다.

아래 문서 목록은 main에 보존한 초기 조사·개발 이력이다. 현재 구현 작업은 work의 최신 상태에서 이어간다.
