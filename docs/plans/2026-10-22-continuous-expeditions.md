# 원작 맵·연속 원정 구현 범위

기준: work 5aed626, 사용자2026-10-22 지시. 단계별 최소 검사·로컬 커밋, 중간 배포 없이 최종 통합 검증 뒤 소스·필요 자산·루트 EXE를 함께 push한다.

## 단계

1. 원작 조사 자료를 검증하고 원정 ID·층·고정 배치·연결부 계약을 만든다. 예상30~60분. 데이터 참조·제외 규칙과 컴파일만 확인한다.
2. 기존 탐험 엔진에 구간 전진·원작 쉼터·최종 완료를 연결한다. 예상60~120분. 기존 전투·생활·사건 기능을 재사용하고 전진·귀환 중복만 최소 확인한다.
3. MDES 저장 호환, 분기·재방문·선택 귀환·실패, 필요한 선택 자산과 맵 확대를 연결한다. 예상60~120분. 관련 저장/참조 검사만 수행한다.
4. 변경 전체의 통합·메모리 검사와 실제 EXE를 최종 확인하고 소스/자산/EXE를 함께 반영한다. 예상30~60분. 실제 Windows11·OS 잠금/절전·장기 성능은 별도다.

- RUN-D001:1→2, RUN-D004:4→5, RUN-D021:21→22→23, RUN-D035:35→36→37, RUN-D041:41→42→43으로 확대한다.
- ARC-M07:8→10→12→14→15→16과 갈림길9/11/13의 왕복을 연결한다.
- 원정 전체/구간/ground ID를 유지한다. 원작 층수, 일반/MH 적 비중, 고정 배치의 적대/우호, 아이템 종류→아이템 비중을 재사용한다. 원작의 전체 전투 수치·스토리 VM·지형 효과를 새로 구현하는 범위는 아니다.
- 36개 진행표·5개 장기 원정·57개 동상은 조사 자료다. 이번 선택8원정 외의 경로, 미확정 연결·퍼즐·테스트·더미·ground 별명은 자동 선택에서 제외한다. 누락된 연결을 임의 귀가/성공으로 대체하지 않는다.

## 완료 기준

채택8개 원정에서 중간 구간/쉼터에서는 귀가하지 않고 마지막에만 성공·귀가·식사·취침을 한 번 실행한다. 중단·재개 시 동일 구간/연결부/확정 결과를 유지하며 선택 귀환·실패는 성공 전진과 구별한다. 필요한 실제 원작 몸체·초상화·타일·아이템·쉼터를 연결하고 최종 실제 EXE에서 확인한다. 지원/미실행/미지원은 각각 기록한다.
