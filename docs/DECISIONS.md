# 설계 결정

## 2026-10-15 — 층 진입·우호 목표·기상/퇴실 정정

- 새 시작점뿐 아니라 이전 층 발밑 좌표도 새 계단/아이템/배우 배치에서 제외한다. 같은 run의 지형 hash를 기존 gameplay journal의 `floor-layout:<runId>:<hash>`로 보존하고 중복 후보는 최대128회 예산 내에서 재생성한다. 분리 슬롯의 방 생성기는 유지하며 방 사각형 겹침과 층 사이 지형 중복을 검사한다. 이전 저장의 지나간 지형은 추측 복원하지 않고 현재 층부터 기록한다. MDES6 배치는 유지한다.
- 평상시 아이템 → 미인사 우호 NPC → frontier → 계단을 따른다. 기존 목표를 완료/실패까지 유지하고 계단 목표는 새 NPC 발견 시 재평가한다. 저체력 열매/계단 생존 우선과 적의 행동권은 유지한다. 대화/인사 journal·자리 교환을 재사용한다.
- 아침 fade-in에는 주인공/동료 Sleep13 마지막 자세를 함께 유지한다. 이어 Wake14 → 인사 →1870ms 퇴실 →750ms fade-out → 검정에서 다음날1회 commit →750ms ExploreFadeIn으로 진행한다. 퇴실 fade에서 몸체/카메라는 통로 끝에 고정한다. 기존 enum10/11을 재사용하며 이전 MDES3/4의 퇴실 전 enum10은 현재 퇴실 경로로 읽는다.

## 2026-10-15 — 사용자 정정: 반복은 같은 층 우회

- 자동 귀가 정책을 폐기한다. 반복 시 같은 층의 합법 인접 칸으로 우회하고 기존 목표로 탐험을 계속한다. 기존 다음 칸/직전 칸을 가능하면 제외하고 공격 구역·미방문·목표 거리 순으로 후보를 정렬한다. 같은 상태가 다시 나타나면 후보 방향을 순환한다.
- 기존 MDES6의32개 fingerprint 기록과 중복 횟수를 재사용하며 후보 한 바퀴마다 해당 상태의 최신1개만 남긴다. 바이트 배치·MDES1~6 읽기는 유지한다. 출구 없음은 대기와 재평가이며 상태가 재계획으로 달라져도 대기 기록을 보존한다. 반복 감지로 귀가·층 전환·클리어·순간이동하지 않는다.
- 수동 Reset만 기존 귀가/생활 루프와 백업·확정 상태 보존을 수행한다. 자동 Reset API와 Windows 자동 귀가/백업 분기를 제거한다. 아래 자동 귀가 결정은 이 항목으로 대체한다.

## 2026-10-15 — 동반 역주행·안전 귀가 Reset

- 적의 추적과 저체력 회피가 동시에 이전 칸으로 되돌아가려 하면 해당 행동에서 미래 공격 구역 제외를 풀고 실제 점유 기반 경로로 목표 진행을 시도한다. 충돌/적의 공격권은 유지한다.
- 최근32개 진행 상태 fingerprint를 MDES6에 저장한다. 반복 시 자동 귀가하며 이전 MDES1~5는 빈 기록으로 읽는다. 방문/발견·목표·HP·획득/배우 상태가 달라진 진행은 구분한다.
- 수동 Reset은 탐험/전투/대화에서 현재 탐험을 중단하고 기존 귀가/생활 파이프라인으로 연결한다. 확정 HP·아이템·완료 journal을 보존하고 미확정 피해/이동/추적을 취소한다. 새 클리어/보상을 지급하지 않는다.
- 자동/수동 복구는 직전 snapshot을 `.reset-backup`에 보존하고 결과를 durable save한 뒤 화면에 공개한다. 귀가/식사는 once 기록을 재사용해 중복 호출/재실행에서도 한 번만 처리한다.
