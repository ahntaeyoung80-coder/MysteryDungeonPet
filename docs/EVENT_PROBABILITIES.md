# 현재 맵·이벤트 출현 정책

2026-10-21 후속 사용자 지시로 모든 지원 맵의 사건 제한을 제거했다. [선택 코드](../src/core/event_runtime.cpp), [공통 확률](../src/core/event_runtime.hpp), [원작 맵 문맥](../assets/original/gameplay/events/provenance.json).

## 맵 선택과 적·아이템

기본 첫 원정은14→15→16이다. 다음 탐험일에는검증된8원정의시작ID1/4/8/14/17/21/35/41중현재원정을제외한7후보를동일하게선택한다. 같은날재시작은일정과맵을유지한다. 길드대원정8과열수의동굴14는서로다른원정이지만일부구간을공유하므로구간별방문비율이균등하다는뜻은아니다. 휴일은별도일정이다. 구형0/15/18과우회로9/11/13은자동원정후보가아니다. [지원범위](CONTINUOUS_EXPEDITIONS.md).

적·일반 아이템의 종류와 상대 출현 비중은 원작 맵·층마다 다르며 그대로 유지한다. 이벤트 종류를 고르는 공통 확률과는 별개다. 맵마다 배치 공간·기존 우호 NPC·이동/전투 시간은 달라 아래 이론 확률이 실제 시간당/층당 발생 횟수가 같다는 뜻은 아니다.

## 모든 지원 맵의 공통 이벤트 확률

선택8원정과3우회로의일반층및구형0/15/18에서탐험사건9종이가능하다. 고정전투층에서는임의탐험사건을시작하지않으며보스전과진행조건을유지한다. 마을·온천 휴일은 탐험 맵 밖의 별도 일정이다.

정기 추첨은 완료 이동16·48·80…걸음에서 안전한 행동 경계를 만났을 때 한 번이다. 동료가 있어야 하고 양쪽 HP가 저체력 기준보다 높으며, 실행 중 문답/사건/이동·공격이 없고 인접 적이 없어야 한다. 층당 시작1회·탐험당 시작2회 상한을 유지한다. 조건을 만족하지 못한 선택은 같은 기회에 다른 사건으로 다시 추첨하지 않는다.

몬스터 하우스5%와 워프834/10000은 이전 던전18에서 쓰던 비율을 모든 맵의 제품 정책으로 적용한 값이다. 원작 데이터의 수치 자체를 바꾸거나 새 원작 함정표가 있다고 주장하지 않는다. 던전15의 원작 MH0/shop0/warp0과18의MH5/shop9/warp 비중834는 보관 자료에 그대로 남는다. 방 진입 추첨이 실패한 같은 갱신에 정기 걸음 조건도 맞으면 정기 추첨까지 시도할 수 있다.

상점은 현재 층의 원작 shopItems category→item 비중으로7회 상품을 추출한다. 별도 문맥이 없는 해안 동굴0은 그 층의 기존 floorItems를 사용한다. MH는 해당 층의 원작 monsterHouse 종 비중을 사용하고 없으면 해당 층 normalFriends를 사용한다. 다른 맵의 상품/적 표를 빌리지 않는다. 실제 오랭 상품+주인공 사과3개+열매 재고 여유가 있어야 교환 분기로 간다. 원작 shopChance9를 추가로 곱하지 않는다.

동료의 일반 잡담은 첫48~72걸음 이후 추가144걸음 슬롯과 안전/근접 조건으로 제한한다. 아이템 반응은 안전한 실제 획득마다 별도1/5(20%)로 한 번 선택하며 다른 대사나 위험이 우선하면 생략한다. 획득/처치 시스템 안내는 확정된 결과마다 표시 대기열에 추가한다.
