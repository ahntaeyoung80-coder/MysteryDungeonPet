# MDES7 — 동료 상태·공격 대상

MDES6의 CRC 앞에 고정76bytes를 추가한다. 이전 MDES1~6 읽기는 유지하며 이전 저장의 동료는 비활성으로 시작해 제품 실행 시 합법 인접 칸에서 활성화한다. 실제 활성화가 불가능하면 상태를 훼손하지 않고 다음 안전한 위치에서 재시도한다.

| 순서 | 타입 | 값 |
| --- | --- | --- |
| 1 | u32 | companion.enabled |
| 2 | u32 | companion.tile+1, 비활성 기본0 |
| 3~5 | u32×3 | HP0~5, 열매0~1, 방향0~7 |
| 6~7 | u64×2 | 행동권 round, 연속 보행 시작UTCms |
| 8 | MoveRecord32bytes | actionId/start/duration/direction/from+1/to+1, 기존 인코딩 |
| 9~10 | u32×2 | 동료 숨김, 적의 확정 공격 대상(0플레이어/1동료) |

동료의 논리 위치·이동 시작/끝·행동권·HP/열매와 피해 대상을 함께 durable commit한다. 던전에서 플레이어와 다른 칸·대각 포함1칸/모서리 준수·배우 비중첩을 검증한다. 층 전환은 함께 새 위치에 배치하고, 일시정지 시 양쪽 이동/보행 시계를 함께 이동한다. 수동 Reset은 확정 상태를 유지하고 두 배우의 남은 이동을 지운다.

기존 MDES3/4/5 모양 생성 회귀는 먼저76bytes 동료 block을 제거한 뒤 종전 필드를 제거하고 CRC를 다시 계산한다. 저장 버전만 바꿔 다른 형식으로 해석하지 않는다.
