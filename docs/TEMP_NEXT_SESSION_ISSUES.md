# 다음 세션 임시 조치 문서

> 이 문서는 다음 세션에서 문제를 수정하기 위한 임시 작업 지시서다. 아래 조치를 완료하고 검증한 뒤 이 파일을 삭제한다.

## 확인된 사용자 체감 문제

1. 캐릭터가 목적지를 향하지 않고 무작위 이동을 반복한다.
2. 계단이 눈앞에 있어도 계단으로 이동하지 않는다.
3. 목적지 도착이나 인카운터 접촉 외에도 계속 이동한다.
4. 3층 클리어 후 Pose 재생과 귀가 재현은 확인됐으나, 귀가 과정이 불필요하게 길다.
5. 귀가 중 캐릭터가 투명해져 목적지와 진행 상태를 알 수 없다.
6. 현재 테스트에서는 귀가 단계가 끝나지 않고 계속 어딘가로 걸어간다.

## 현재까지의 판단

귀가 상태로 전환된 뒤에도 탐험용 이동 로직이 활성화되어 있는 상태로 추정한다. 특히 다음 가능성을 우선 점검한다.

- `ReturnHome` 전환 시 `Explorer`/`Navigator`가 정지하지 않음
- 기존 계단·frontier 목표 또는 이전 경로가 귀가 상태에서도 유지됨
- 귀가 목적지의 도착 판정 또는 귀가 완료 이벤트가 발생하지 않음
- 경로 실패 시 재계획이 무한 반복됨
- `fade-out → 집 씬 전환` 이벤트가 연결되지 않음
- 귀가 완료 후 `Eat`/`Sleep`으로 이어지는 상태 전환이 누락됨

## 목표 동작

```text
3층 계단 도착
  → Pose17 유한 재생
  → 탐험 이동 즉시 중지
  → 0.5~1초 fade-out
  → 월드 이동 없이 집 씬으로 전환
  → 0.5~1초 fade-in
  → Eat
  → Sleep
```

귀가 중 필드에서 실제로 걸어가는 연출은 사용하지 않는다. 귀가 시간은 이동 경로에 따라 길어지면 안 되며, Pose 종료부터 집 장면 표시까지 약 1~2초를 목표로 한다.

## 수정·검증 순서

1. `ReturnHome` 진입 시 탐험 이동, 경로 재계획, 기존 목표 갱신을 차단한다.
2. 귀가 전환을 물리적 이동이 아닌 장면 전환 이벤트로 분리한다.
3. `ReturnHome` 이벤트가 한 번만 실행되도록 `onceKey` 또는 동등한 중복 방지 장치를 둔다.
4. fade-out 완료 후 집 씬을 교체하고 fade-in한다.
5. 집 씬 표시 후 `Eat → Sleep` 전환을 확인한다.
6. 다음 시나리오를 측정한다.
   - 계단이 바로 앞에 있을 때 계단으로 이동하는가
   - 목표가 없을 때 무작위 이동하지 않는가
   - 3층 클리어 후 더 이상 필드에서 걷지 않는가
   - 귀가 전환이 1~2초 안에 끝나는가
   - 귀가 후 식사와 취침으로 이어지는가
   - 이벤트가 반복 실행되거나 귀가 상태에 고착되지 않는가

## 검증 시 기록할 로그

최소한 다음 상태 전환을 시간과 함께 기록한다.

```text
Explore
→ Pose
→ ReturnHome
→ FadeOut
→ Home
→ FadeIn
→ Eat
→ Sleep
```

`ReturnHome` 진입 이후 `Navigator.plan` 또는 이동 tick이 호출되면 실패로 기록한다. `Home` 전환 없이 `ReturnHome`이 5초 이상 지속되면 실패로 기록한다.
