# 반복 감지 후 같은 층 우회 — 2026-10-15

사용자 정정: 반복은 자동 귀가 사유가 아니다. 탐험을 유지하고 다른 방향으로 이동한다. 우클릭 수동 Reset만 귀가를 수행한다. 이전 자동 귀가 명세/검증은 이 명세로 대체한다.

| 단계 | 목표 | 완료 기준 |
| --- | --- | --- |
| 1 분석·회귀 | 자동 귀가가 요구와 다른 지점을 고정 | 저장된 반복 상태에서 같은 층의 다른 칸으로 이동해야 하는 회귀가 기존 코드에서 실패, 명세·원본 실패 로그 커밋 |
| 2 우회 구현 | 반복 경로를 벗어나 탐험 계속 | 반복 시 정상 다음 칸/직전 칸 대신 합법 인접 칸 선택, 같은 상태 재등장 시 우회 후보 순환; 벽·모서리·점유·공격권·획득 상태·층 유지; 유일 출구/출구 없음·저체력/일반 체력·매행동 저장 복원 회귀 통과, 구현 커밋 |
| 3 Windows·인수인계 | 실제 앱과 최신 EXE에 반영 | Windows에서 반복 감지→다른 방향 이동·귀가 없음 및 수동 Reset 회귀 통과; EXE/source/assets hash 일치, 안내/현재 상태 갱신, 결과 커밋·work push |

반복 기록은 기존 MDES6의 최근32개 fingerprint를 재사용한다. 같은 fingerprint의 재등장 횟수로 우회 후보를 순환하며 저장/재실행 후에도 같은 결정을 재현한다. 적의 현재 행동권을 먼저 처리한다. 우회 후보는 실제 점유/지형을 통과할 수 있는 인접 칸이며, 가능하면 반복 경로의 다음 칸과 직전 칸을 모두 피한다. 적 공격 구역·미방문·목표 거리 순으로 후보를 정렬한다. 우회가 불가능하면 기다려 다음 행동에서 다시 평가하며 반복 감지 자체는 귀가/층 전환/보상/순간이동을 발생시키지 않는다.
