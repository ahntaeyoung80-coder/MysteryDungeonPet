## 정밀 검토 결과

- 앞선 미반영 후보 32개는 별도 초안 목록에서 제거했다. 관찰·호기심·작은 농담·걱정·계획을 실제 발생하는 장면에 맞춰 완성 대본에 통합했다. 체력·요일 세부 조건이나 종별 말투 선택 기능을 새로 약속하지 않는다.
- 노공룡은 힘찬 장음, 동료는 친근한 반말을 유지한다. 이름이 확정된 비버니는 소박한 어미, 가재군은 활기찬 인사, 온천 주인은 느긋한 하게체를 사용한다. 일반 NPC는 종별 성격을 고정하지 않고 상황에 맞춰 말한다.
- 기상 외침은 아침 식사나 식당 방문을 약속하지 않는다. 아침 흐름은 기상→인사→퇴실→출발이며 식사는 귀가 후다.
- 열매 전달 제안은 거래 전의 말이다. 전달 뒤에만 감사를 표시하며 NPC가 실제로 먹거나 회복했다고 단정하지 않는다. 길 안내에는 치료 대사를 섞지 않는다.
- 교환 방향은 사과 3개 지불→오랭열매 1개 수령이다. 구경 경로에 교환 완료 대사를 넣지 않는다.
- 보스 대화는 승리 후 화해 장면이다. 친구 기록의 확정 전에는 이미 친구가 되었다고 말하지 않고, 팀 합류·재방문 보상은 약속하지 않는다. 입장 경고는 열매 소지를 가정하지 않는다.
- 패배 대사는 걷기 어려운 상태를 다루며 즉시 회복을 보장하지 않는다. 플레이어 답변·침묵 설명을 덧붙이지 않는다.
- 모든 발화는 26폭×2줄의 한 페이지다. 같은 상황의 선택지를 서로 다르게 썼다. 워프 함정·몬스터 하우스처럼 같은 사건을 알리는 표시문은 일관된 문구를 유지한다.
- 장면마다 선택된 묶음은 저장하며 직전 묶음을 피한다. 아직 없는 장기 반복 방지나 NPC 성격 분기 기능을 적용 완료로 표시하지 않는다.
