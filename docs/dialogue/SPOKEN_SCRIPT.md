# 대화 대본 — 검토·수정용

이 문서에서 문장·화자·표정을 직접 고친 뒤 반영을 요청하면 된다. 코드나 ID를 이해하지 않아도 장면별로 읽을 수 있도록 정리했다. 아래의 **현재 적용 대본**은 이번 수정의 실행 대사 전체이며, 뒤의 **추가 대본 초안**은 아직 게임에 넣지 않은 후보다. 상태·획득·회복·제목 문구는 [출력 텍스트](DISPLAY_TEXT.md)에서 다룬다.

## 집필 기준

- 플레이어는 과묵하다. 상대가 말한 뒤 반드시 플레이어의 답을 넣지 않는다. 고개 끄덕임 같은 동작도 매번 글로 설명하지 않는다.
- 노공룡은 아침을 힘차게 알린다. 동료는 일어난 뒤 밝게 인사한다. 같은 장면에서 같은 인사를 두 번 하지 않는다.
- 동료가 언제나 “함께라서 든든해”, “천천히 가자”, “잘 챙겨 두자”로 끝나지 않도록 관찰·호기심·작은 농담·계획·감사를 섞는다.
- 다친 상대와 패배 장면에서는 밝은 농담을 쓰지 않는다. 상대의 상태와 실제 처리 결과에 맞는 말을 한다.
- 한 번의 발화는 가능하면 2줄 한 화면 안에서 끝낸다. 지금은 한 줄 26폭(한글 13자 정도), 2줄을 한 페이지로 사용한다. 긴 문장을 억지로 잘라 다음 페이지에서 반복해서 보여 주지 않는다.
- 초상화는 실제 화자가 말할 때만 표시한다. 대화가 없을 때는 숨긴다. 플레이어의 침묵이나 시스템 안내에 플레이어 초상화를 붙이지 않는다.
- 현재 선택은 상황마다 무작위이며 직전 묶음을 피한다. 말투가 다른 캐릭터별 대사 선택, 상황 세부 조건, 긴 기간의 반복 방지는 아직 연결되지 않았다. 아래 후보의 조건을 구현된 것처럼 표시하지 않는다.

## 현재 적용 대본

기준: catalogueVersion 10. JSON 원문 기준 120묶음이다. 화면에 들어가는 자동 줄바꿈을 제거한 원문으로 실었으며, 이어지는 여러 발화가 있으면 각각 행을 나눴다. 표의 키는 반영할 때 문장을 찾기 위한 표식이므로 수정하지 않아도 된다.

## 다음 편집 때 확인할 점

1. 위 현재 대본에서 반복되는 마무리와 어색한 조사를 먼저 고친다.
2. 새 후보는 실제로 발생하는 장면에 배치한다. 아직 모르는 사실을 알려 주거나 없는 기능의 사용을 약속하는 말은 넣지 않는다.
3. 같은 내용의 획득 안내와 동료 감상을 연달아 매번 보여 주지 않는다. 동료 감상은 현재 획득의 약 20%에서만 나온다.
4. 수정 요청에는 키와 새 문장을 쓰거나 이 문서를 직접 수정하면 된다. 문서 편집만으로 실행 파일은 바뀌지 않는다. 적용할 때 현재 대본은 실행 데이터에 옮기고, 후보는 조건과 함께 별도로 연결·검사한다.
