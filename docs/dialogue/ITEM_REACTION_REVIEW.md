## 검토 기준

- 오랭열매만 자동 회복한다. 다른 씨앗·장비·구슬·기술머신은 획득 감상으로 쓰고 효과 발동·기술 습득·장착 성공을 알리지 않는다.
- 전용 능력·성별·팔/꼬리/날개 보유를 단정하지 않는다. 동료가 누구로 선택되어도 발화할 수 있게 쓴다.
- 플레이어의 답변을 대신 만들어 “네가 그렇게 말했다”는 식으로 받지 않는다. 이전에 헤어졌다는 등 확인되지 않은 사건을 전제하지 않는다.
- “이름이 낯설다/따로 넣자/알아보자”가 연이어 나오는 부분은 동료의 짧은 농담·길드/풍경 연상·함께 가자는 마음으로 분산한다.
- 구미의 색과 구슬/기술의 이름에서 감상을 얻되 원본 효과를 추측하여 기능 설명으로 굳히지 않는다.
- 모든 문장은 두 줄 한 페이지로 유지한다. 수정하지 않은 문장도 아이템 일치·반복·표현 길이를 확인했다.
