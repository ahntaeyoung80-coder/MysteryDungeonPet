# 오랭열매 사용 검증 — 2026-10-23

현재 코드와 아래 재현 검사에서는 재고가 무한히 되살아나는 현상을 발견하지 못했다. 사용자가 보았던 당시 저장·추적 로그를 직접 대조한 결과는 아니므로, 원래 관측한 현상의 원인을 확정한 것으로 표시하지 않는다.

## 실제 동작

- 플레이어와 동료는 별도의 오랭열매 재고를 가진다. 한쪽이 먹은 직후 다른 쪽도 먹을 수 있다.
- 하트가 1~3이고 재고가 있으면 1개를 소비해 최대 5하트로 회복한다. 전투·탐험·독립 파티 경로 모두 실제 재고를 1개 줄인다. 사용 알림은 약 2초이며, 글자가 표시되는 프레임마다 다시 소비하는 구조가 아니다.
- 일반 원정층에는 최소 1개가 있도록 공급한다. 원래 보장 목록에 없다면 앞에 추가한다. 기존 무작위 출현은 남아 있어 한 층에서 더 얻을 수 있다. 보스 고정층과 명시적인 무아이템 조건은 제외하며 배치 공간·예산을 지킨다. 층이 많은 원정에서는 공급이 계속되므로 사용 횟수가 많을 수 있다.
- 같은 아이템은 획득 완료 상태와 고유 획득 기록으로 재획득을 막는다. 저장 복원은 그 상태와 두 재고를 그대로 읽는다. 다음 층을 생성할 때의 새 공급과 같은 층 저장을 불러올 때의 복원은 다르다.
- 획득 이력(`inventory`)은 누적 획득 기록이다. 먹었다고 과거 획득 기록을 지우지는 않으므로 이력의 열매 개수가 현재 재고는 아니다. 현재 재고는 플레이어 `oran`, 동료 `companion.oran`이다.
- 물물교환은 사과 3개를 소모하는 별도 거래다. 나눠 주기는 소유 열매를 줄인다. 이번 작업에서 공급·회복량·거래 규칙은 바꾸지 않았다.
