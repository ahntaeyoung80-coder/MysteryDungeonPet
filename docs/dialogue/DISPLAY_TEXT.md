# 출력 텍스트 — 상태·알림 검토용

캐릭터가 직접 말하는 [대화 대본](SPOKEN_SCRIPT.md)과 분리한 화면 문구 문서다. 이름·조사·길이·중복을 이 문서에서 검토한다. **현재 적용 문구**와 **수정 후보**는 구분한다. 문서를 수정한 뒤 적용을 요청하면 실행 데이터·코드와 맞춰 반영한다. 이 문서를 고치는 것만으로 EXE가 바뀌지는 않는다.

## 표시 규칙

- 184×48 패널에 2줄을 사용한다. 기본 글자는 12픽셀이며, 대사는 한 줄 26폭·2줄 단위로 미리 나눈다. 짧은 문장을 일부러 두 페이지로 만들지 않는다.
- 대사가 없을 때는 PC 상태를 보여 준다. 초상화는 기본 숨김이며 실제 발화 때 상대의 얼굴만 보인다. 상태·획득·회복·전투 결과 안내는 발화가 아니므로 얼굴을 붙이지 않는다.
- 일반 문장은 한 글자씩 나타나고 충분히 읽을 시간을 둔다. 같은 내용의 안내를 두 번 출력하거나 단어 중간에서 페이지를 갈라 놓지 않는다.
- 아래 `〈값〉`은 실제 이름·개수·층수로 바뀌는 부분이다. 값의 숫자가 내부 ID라는 이유만으로 사용자에게 그대로 보이지 않도록 한다.

## 문서 편집 방법

현재 문구는 행의 문장만 고쳐도 된다. “미반영 후보”를 채택하려면 현재 문구에 옮기거나 채택 표시를 남긴다. 서로 겹치는 안내를 지우고 싶다면 해당 행에 삭제 의도를 적는다. 최종 적용 시에는 화자·표정·실제 조건·한 화면 길이·저장 복원을 함께 확인한다. 개발자용 오류창·파일 경로·CLI 설명은 이 게임 화면 문구 문서의 대상이 아니다.
