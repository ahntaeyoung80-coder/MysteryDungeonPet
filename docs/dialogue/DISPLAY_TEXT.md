# 출력 텍스트 — 상태·알림 검토용


2026-10-23 KST 문서 완성본. [대화 대본](SPOKEN_SCRIPT.md)과 함께 검토한 화면 문구와 선택 아이템 156개×3반응(468개) 전체다. 문서 검토 후 실행 데이터와 기본 출력 경로에 반영했다.

## 표시 규칙

- 184×48 패널에 2줄을 사용한다. 기본 글자는 12픽셀이며, 대사는 한 줄 26폭·2줄 단위로 미리 나눈다. 짧은 문장을 일부러 두 페이지로 만들지 않는다.
- 대사가 없을 때는 PC 상태를 보여 준다. 초상화는 기본 숨김이며 실제 발화 때 상대의 얼굴만 보인다. 상태·획득·회복·전투 결과 안내는 발화가 아니므로 얼굴을 붙이지 않는다.
- 일반 문장은 한 글자씩 나타나고 충분히 읽을 시간을 둔다. 같은 내용의 안내를 두 번 출력하거나 단어 중간에서 페이지를 갈라 놓지 않는다.
- 아래 `〈값〉`은 실제 이름·개수·층수로 바뀌는 부분이다. 값의 숫자가 내부 ID라는 이유만으로 사용자에게 그대로 보이지 않도록 한다.

## 아이템 효과·표현 대조 결과

| 대상 | 확인한 실제 처리 | 완성본의 표현 기준 |
| --- | --- | --- |
| 오랭열매(70) | 각자 최대 1개. 하트 1~3에서 자기 것 우선, 없으면 상대 것을 1개 소비해 최대 5하트 회복 | 획득은 회복 준비, 사용 알림만 먹었다고 표시. 피로·허기 회복과 혼동하지 않음 |
| 사과(109) | 재고 저장, 물물교환에서 플레이어의 사과 3개 소비 | 먹고 싶다는 감상만 허용. 귀가 공동 식사는 연출/식사 횟수 기록이며 사과 재고를 소비하지 않음 |

이름·원본 효과 설명과 이 런타임의 자동 사용을 구분했다. 전투·이동·회복에 새 아이템 효과를 추가하지 않았다. 비슷한 색 구미와 비슷한 이름 구슬은 이름 차이를 활용하고, 기술머신은 각 이름에 맞는 감상으로 바꿨다. 같은 접미사 세 개에 이름만 갈아 끼우던 반응을 제거했다. 회복량·재고·처치 안내를 새로 늘리지 않았다.
