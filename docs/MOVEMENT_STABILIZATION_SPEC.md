## 고정 시나리오와 판정

기존 4초 무작위 탐험은 대화/전투에 가려져 이동 관찰이 보류됐다. 새 검사는 정상 MDES5 snapshot을 입력으로 사용하고, 일반 앱의 탐험·Motion·Animator·합성·Windows 창 제출 경로를 실행한다. 일반 제품 UI에 시험 동작을 추가하지 않는다.

| ID | 조건 | 판정 |
| --- | --- | --- |
| M1 | NPC/아이템 없는 직선 경로 | 연속 이동마다 400ms, 중간 raster 위치 관측, 끝점 연결 |
| M2 | 대각선과 방향 전환을 포함하는 경로 | 8방향 계약, 이동 거리/시간, Walk 위상·marker/deadline 보존 |
| M3 | 이동 중 pause/resume 및 MDES5 복원 | pause 동안 위치 고정, 재개/복원에서 남은 구간과 도착 유지, 효과 중복 없음 |
| C1 | 네 변·네 모서리와 카메라 추적 시작 경계, 1/2/3배 | camera 범위·같은 좌표계·alpha255·정지 화면 불변 |
| R1 | 기존 도주/공격/인사/자리 교환/층/생활/구버전 저장 | 기존 회귀 유지, 현재 MDES1~5 읽기·MDES5 쓰기 유지 |

기계적 위치·alpha 검사와 실제 화면의 육안 품질은 구분한다. Windows Server CI는 사용자 Windows11·OS 사건·장기 성능 증거가 아니다. 네이티브 GUI를 실행하지 못한 항목을 코어 검사로 통과시키지 않는다.
