# 우호 NPC 정식 우선순위

미인사 우호 NPC를 아이템 다음·frontier/계단 이전의 일반 목표로 올렸다. 발견되고 접근 가능한 우호 NPC의 인접 칸을 BFS로 선택한다. 계단 이동 중 발견한 NPC도 재평가하며, 기존 item/NPC 목표는 완료/실패까지 유지한다. 저체력은 기존 열매/계단 생존 목표를 우선하고 적은 인사 목표에서 제외한다. 경로를 막는 NPC의 대화/자리 교환은 기존 규칙을 재사용한다.

경로 밖 NPC의 접근→플레이어 인사→NPC 응답→greet journal1회·저장 재실행 중복 없음, 아이템 우선/진행 중 NPC 목표 유지, 계단 재평가, 저체력 생존/적 제외 회귀를 통과했다. 기존 revision/survival/navigation 회귀3/3(0.61초) 통과다. 다음은 수면 자세·퇴실 페이드와 실제 Windows 검증이다.
