# 간단한 출력·팀 열매·아이템 반응·보스와 친구 되기

## 확정 동작

- 적을 쓰러뜨렸다는 화면 안내를 제거했다. 새 알림을 만들지 않고 과거 저장에 남은 처치 알림도 지운다. 실제 전투 결과·기절·승리 처리는 유지한다.
- `내 열매 N개 / 동료 N개`와 PC 뒤의 행동 접미사를 제거했다. 대사·알림이 없을 때는 `PC 사용 중`/`PC 쉬는 중` 등 PC 상태만 표시한다.
- 회복 문구는 `오랭열매를 먹었다.`다. 각자 최대1개의 소지 한도는 유지하며 자기 열매를 먼저 쓰고, 없으면 상대의 열매 하나를 소비해 먹은 배우가 회복한다. 전투·탐험·독립 파티와 빈 재고 도주·사건 철수 판단을 함께 맞췄다.
- 아이템156개에 각각3개, 총468개 동료 반응을 작성했다. 약20%의 안전한 획득에서 하나를 고르고 같은 아이템의 최근 반응을 피한다. 원문은 `assets/original/gameplay/dialogue/item_comments.json`, 생성 표는 `src/core/item_comments.inc`다. `python -m tools.compile_item_comments`로 재현한다. 지도·전투·사건 RNG 대신 대사 RNG만 사용한다.
- 선택된 반응 번호를 MDES19의 작은 후행 블록에 저장한다. 앞선18개 버전의 블록 배치는 유지하며 MDES1~18을 계속 읽는다. 기존 반응은0으로 읽는다. 선택·폭·버전/길이·범위·CRC 검사와 복원을 확인한다.
- 최종 고정층에서 마지막 보스의 기절 재생이 끝나면 적대를 해제하고, 보스·동료가 대화8묶음 중 하나를 진행한다. 대화 후 친구 기록을 커밋하고 중앙 이동·클리어·귀가로 잇는다. 여러 보스는 대표가 말하며 전원 친구 상태로 표시한다. 친구가 서서 중앙을 막지 않게 자리를 정리한다. 보스가 없는 층은 기존 중앙 클리어로 간다.
- 친구 기록은 기존 gameplay journal의 배우별 키에 저장하고 다음 날에도 복사한다. 재방문 전투를 없애는 별도 정책은 추가하지 않았다. 플레이어 대사는 추가하지 않았다.
- [대화 대본](../dialogue/SPOKEN_SCRIPT.md)은 현재120묶음·157발화와 미반영 후보32개다. [출력 텍스트](../dialogue/DISPLAY_TEXT.md)는 아이템별3개 반응을 전부 실었다. 현재 카탈로그는 version10이며157발화 모두2줄 한 페이지다. [열매 규칙](../dialogue/ORAN_AUDIT.md)과 실행 안내도 함께 갱신했다.

최초9개 실행은8통과·event_combat 하나 실패(총23.64초, social21.76초)였다. 공유 회복으로 기존 seed42/1/7의 전투가 모두 승리하여 “승리와 퇴각 모두 관측” 기대가 맞지 않았다. 공급 없는 seed99를 추가해 재확인했지만 모두 건강하게 시작하면 이 경우도 승리했다. 이 중간 상태는 기본/동료 호환 검사와 별도 직접 실행에서 다시 확인했다. 제품 전투 수치를 바꾸지 않고 seed99의 시작 부상을3하트로 둔 fixture를 추가했다. 정상 퇴각을 확인한 뒤, 공격 없이 퇴각한 사례에 승리의 공격 참여 기대를 적용하던 검사도 분리했다. 최종 해당 검사만 재실행해 통과했다(0.56초). 이미 통과한 다른 검사는 반복하지 않았다.

기본/동료 호환 검사는 각각7.72초/32.74초에 통과했다. 후속 친구 기록의 다음 날 보존과 실제 MDES18 입력 fixture를 보완한 뒤에는 social_feedback/berry_capacity/package_transition만 다시 실행해3개 통과(13.30초, social11.19초)했다. 그 외 코드 경로의 앞선 통과 결과를 재사용한다.

Python 대사6개·아이템 반응2개, 합계8개 통과. 원문 컴파일 재현·두 줄 길이·각 아이템3개·중복/과도한 길이 거부·화자 계약을 확인했다. Windows x64 static Release에서도 social_feedback와 실제 GDI 텍스트 검사2개를 Wine에서 실행해 통과했다. 친구 보존 보완 후 Windows social_feedback를 다시 통과시켜 최종 EXE에 맞는 화면 fixture를 만들었다.

## 실제 EXE 화면

처음6개 화면 실행은 모두 정상 종료0이다. 보스 외5개는9.24~9.90초, 보스는27.35초였다. 친구 보존 보완 후 최종 보스 화면을 다시28.21초 실행해 정상 종료0, 보스/동료의1101/1102/1103 세 발화·완료 연출·귀가·식사·취침 진입을 확인했다. 최종 저장은 적대 배우0·식사1이며 `boss-friend:415`를 보존한다. 최종 저장을 실제 decoder로 읽어 구조/CRC도 확인했다.

- 대기: 초상화 없음·PC 상태만.
- 처치: 처치 알림 없음.
- 팀 회복 양방향: 빈손인 배우가 상대 열매 사용, 두 배우5하트·소모 재고0 유지, 짧은 문구만.
- 구슬: 선택된 동료 반응과 눈빛 반짝임.
- 보스: 실제 해당 보스 초상화 → 동료 응답 → 보스 답변 → 성공·귀가.
