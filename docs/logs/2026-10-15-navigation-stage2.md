# 경로 진동 수정·자동 복구

적이 직전 이동을 거슬러 가고 플레이어의 안전 경로도 직전 칸으로 되돌아가려 하면, 그 한 행동에서는 미래 공격 구역 mask를 풀고 실제 점유를 지킨 목표 진행 경로로 다시 계획한다. 적의 점유·충돌·남은 공격권은 유지한다. 위협을 계속 피해 같은 두 칸을 왕복하던 원인을 처리한다. 원래 재현은4번째 이동에서 다른 칸으로 진행하고 정상 전투로 연결됐다.

추가로 최근32개 joint-state fingerprint를 MDES6에 저장한다. 위치·방문/발견·목표·소지·HP·추적/행동권이 같은 상태가 반복되면 안전 귀가한다. 새 진행 상태와 시간 경과를 구분하고 저장 재실행으로 감지 기록이 없어지지 않게 했다. 기존MDES1~5를 읽는다.

Release10/10(15.07초), 원래 재현 회귀, 매행동 저장/복원의 저체력200배치, 반복 상태 복원/자동 귀가·중복 귀가 차단·새 진행 오탐 방지·MDES5이전/과대 history 거부 통과. MinGW x64 compile/link와 루트 EXE/source/assets hash를 확인했다. ASan/UBSan 결과와 실제 Windows 검사는 후속 통합 기록을 따른다. 다음은 우클릭 Reset과 실제 Windows 원래 배치/자동 복구/Reset 검증이다.
