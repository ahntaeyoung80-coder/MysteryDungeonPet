# 동료 상태·추적·MDES7

별도 동료 위치/HP/열매/방향/행동권/보행·MoveRecord와 확정 적 공격 대상을 MDES7에 저장한다. 이전 MDES1~6 읽기를 유지한다. 합법 인접 칸 활성화, 플레이어 직전 칸 우선 추적, 후진 교대, 층 동반 배치/이전 발밑 제외, 일시정지·Reset·다음날 연결을 구현했다.

이동은 지형/모서리/점유를 지키며 대각 포함1칸·비중첩을 유지한다. 좁은 길의 우호 NPC는 인사 후 빈 앞/옆 칸으로1칸 비켜 팀을 통과시킨다. 단독 플레이의 기존 자리 교환은 유지한다. 벽 모서리 때문에 직접 못 가는 인접 좌표를 전역 경로에서 잘못 막아 다른 길까지 잃는 경우를 회귀에서 발견해 실제 즉시 이동 가능 칸만 검사하도록 수정했다.

16방향/후진·부분 이동 복원/일시정지, 미인사/인사 완료 NPC 통로, 100개 seed의3층 탐험과9,941회 매행동 복원, MDES6 이전/과거1~5 읽기·중첩 거부를 통과했다. 기존 전체 Release12/12(20.69초) 통과. 독립 배우의 전투와 실제 Windows 기본 활성화/표시는 다음 단계다. 실행물은 통합 후 갱신하며 아직 원격 push하지 않았다.
