# 2줄 대화창·노공룡 복구·열매 검증·대본 문서

## 범위와 변경

사용자 후속 지시대로 184×48의 2줄 패널로 변경했다. 본문은 x16~183/y152~183이며 12px 글꼴과 단어 단위 줄바꿈을 사용한다. 대사 컴파일러와 runtime 검증을 26폭×2줄 페이지로 맞췄다. 현재 112묶음·133발화는 각각 한 페이지로 들어가므로 이전처럼 한 문장을 두 화면에 나눠 보여 주지 않는다. 2줄을 넘는 미래의 긴 대사는 필요한 경우에만 다음 페이지를 사용한다.

이전 피드백에서 `wake.alarm`의 화자를 동료로 바꿔 노공룡의 말이 없어졌다. 이를 노공룡/밝은 표정의 기상 외침 8개로 복구했고, 동료의 밝은 인사는 출발 준비에 유지한다. 동료가 없는 경우에도 길드의 노공룡 기상 외침은 가능하다. catalogueVersion은 9다. 이전 버전의 활성 대사는 기존 버전 불일치 복원 정책으로 정리하며 저장 형식은 바꾸지 않는다.

기본 초상화는 숨기고 실제 발화 중 화자 하나만 표시한다. 상태·획득·회복 안내에는 얼굴을 붙이지 않는다. 2줄 패널과 겹치지 않게 초상화 프레임을 y88~143, 얼굴을 y96~135로 올렸다. 상시 PC 상태 패널은 유지한다.

## 오랭열매

소모량 변경이나 재고 보정은 하지 않았다. 코드와 재현 검사에서 무한 사용은 발견하지 못했다. 플레이어와 동료의 재고는 따로 있고, 일반층마다 보장 공급과 기존 무작위 공급이 있으므로 자주 회복할 수 있다. 누적 획득 이력은 소모품의 현재 재고가 아니다. 원래 사용자 장면의 저장·추적을 직접 대조한 것은 아니므로 관측 원인을 확정하지 않는다.

회복 메시지 둘째 줄에 두 재고를 표시하고 이동 추적 CSV에 `player_oran`, `companion_oran`을 추가했다. [별도 검증 문서](../dialogue/ORAN_AUDIT.md)에 실제 규칙·검사·관측 수단을 기록했다.
