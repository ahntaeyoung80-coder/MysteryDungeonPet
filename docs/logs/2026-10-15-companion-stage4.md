# 동료 4단계 — 몸체·표시·생활

- 동료는 기존 두 번째 파이리(MD4/sprite4), 적/우호 NPC는 사용자 최종 지정 초록색 켈리몬(MD383/sprite556·도감352)이다. 생활 장면 동료도 파이리 자산을 유지한다.
- 기존1개 적 몸체와 생활 동료를 공유하던 경로를 분리하고 기본 제품 실행에서 동료를 활성화한다. 기존 단독 회귀 snapshot만 검사 전용 `--solo`로 실행한다. 일반 실행·설치 실행은 기본 party다.
- 파이리의 별도 Motion/Animator/완료 신호/저장·일시정지 복원을 연결하고 두 번째 HP5칸을 표시했다. 방 지원 이동/공격/피격/기절, 함께 Pose·귀가/생활/다음날을 연결한다. 적 몸체 방향도 실제 선택한 공격 대상을 따른다.
- 켈리몬 원작 dungeon0/1/6/7의160프레임을 원본 WAN/병합/atlas 픽셀·tick·marker 대조 통과했다. 없는 전용 인사22/기절33은 조작한 자산을 만들지 않고 유한 Idle7 응답/유한 Hurt6 퇴장으로 처리한다. 출처와 누락을 자산 provenance에 기록했다. 원본 ROM은 불변이다.
- Release12/12(23.41초), MinGW x64 Release, 변경 PowerShell 구문 검사 통과. 루트 EXE/source/assets hash 갱신. 실제 Windows 추적·전투·방/통로·기절과 파이리/켈리몬 제출 픽셀 비교를 추가했으며 실제 결과는5단계에서 확인한다.
