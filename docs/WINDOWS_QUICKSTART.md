# Windows 실행

실행 중이면 우클릭 **Exit**로 종료한다. GitHub Desktop에서 `work`를 pull한 뒤 저장소 루트의 **MysteryDungeonPet.exe**를 더블클릭한다. ZIP 생성·다운로드·압축 해제·사용자 빌드는 필요 없다. EXE와 `assets/`를 저장소 안에 함께 둔다.

기본 새 탐험은7층이다. 기존3층 저장은 진행 중인 탐험을 유지하고 정상 생활 뒤 다음날부터7층으로 전환한다. 명시적 `--explore`는 지정 패키지의 층수를 따른다. 기본 실행은 기존 저장 복원 또는 자동 던전 탐험으로 시작한다. 저장과 로그는 `%LOCALAPPDATA%\MysteryDungeonPet`에 기록한다. pull로 기존 저장을 지우지 않는다. 다른 작업 폴더에서 EXE를 실행해도 자산은 EXE 위치를 기준으로 읽는다.

## 현재 동작

- 파이리 동료가 함께 탐험한다. 평상시 가까이 추적하며, 전투 중에는 자신의 적을 마무리한 뒤 주인공에게 합법 최단 경로로 복귀한다. 화면에는 주인공 HP만 표시하며 동료의 내부 HP·피해·회복은 유지한다.
- 녹색 켈리몬은 우호 NPC, 보라색 켈리몬은 적이다. 원작 MD383/sprite556과 MD384/sprite554를 각각 사용하며 저장 복원 뒤에도 관계를 유지한다.
- 주인공·동료·각 적은 라운드별 행동을 따로 처리한다. 통로 양쪽의 적과 같은 라운드에 싸울 수 있고 한 적이 쓰러져도 다른 전투를 계속한다. 동료의 적극 접근은 방/통로의 합법 경로를 따른다. 이동한 행동에 추가 공격하지 않는다. 어느 아군이든 기절하면 함께 귀가하고 다음날 둘 다HP5로 회복한다.
- 평상시 아이템 → 미인사 우호 NPC → 미탐색 영역/frontier → 발견된 계단. 주인공 저체력 도주는 진행 중인 동료 전투를 취소하지 않는다. 이동 불가·공격 가능이면 전투하고, 둘 다 불가하면400ms 대기 후 재평가한다. 포위·반복만으로 자동 귀가하지 않는다.
- 오랭열매는HP3 이하에서만 사용한다. 열매 사용·아이템 획득은 각각1턴을 소비한다. 우호 NPC를 목표로 찾아가며, 길을 막는 우호 NPC와 처음 만나도 인사·응답 후 동료가 들어갈 칸도 확보하며 비켜서 통과한다. 같은 NPC와의 인사는 반복하지 않는다.
- 계단 도착 →1초 fade-out → 다음 층 commit →1초 fade-in → 탐험 재개. 새 시작점과 이전 층 발밑 좌표에는 계단·아이템·배우를 배치하지 않는다. 같은 run의 원시 지형과 최근64개 전체 지형의 평행이동 중복을 거부하며 다음날도 기억을 이어간다. 개별 방의 같은 크기는 허용하고 방 영역은 서로 겹치지 않는다. 사용자가 보고한 방 중복의 정확한 장면 유형은 아직 미확인이다.
- 노란 원반은 던전의 우호 NPC에게만 보인다. 플레이어·파이리 동료·적·대화·생활 장면에는 없다.
- 공동 식사는7초다. 밤 침실에서 동료와 인사한 뒤 눕기·잠들기 animation을 한 번 재생하고 바로 fade-out/in으로 아침으로 전환한다. 수면 정지 장면과2초 대기는 생략한다.
- 동료와 함께 취침한다. 아침 fade-in 동안 두 배우의 잠든 마지막 자세 유지 → 두 배우 Wake14 → 두 배우 Nod22 인사 → 주인공 Walk0 왼쪽 통로 입구까지 약1.9초 이동 →750ms fade-out → 검정에서 다음날 전환 →750ms 탐험 fade-in. 동료 침상을 피해 맵 안에서 퇴실을 끝낸다.
- 피해는 각 공격의 완료 소유자와 action ID를 확인한 뒤 대상에게1회 반영한다. 저체력 도주와 적 추적 이동은 같은400ms에 표시해 매 걸음 사이 별도 휴식이 없다.
- 새 저장은 MDES8이며 MDES1~7도 읽는다. 기존 저장을 지우지 않고 합류 가능한 인접 칸에서 동료를 추가한다. 기술 선택·레벨·가방 등은 기존 범위 그대로다.

대각선 왕복은 동반 역주행 재계획으로 수정했으며, 같은 진행 상태가 반복되면 기존 다음 칸/직전 칸을 피하는 다른 방향으로 우회해 같은 층의 탐험을 계속한다. 같은 상태가 재등장하면 우회 후보를 순환하며 갈 수 있는 칸이 없으면 기다렸다가 다시 평가한다. 반복 감지는 귀가를 수행하지 않는다.

우클릭 메뉴는 Hide·Always on top·Scale1..3·**Reset 탐험 (귀가)**·Exit다. 탐험/전투/대화 중 Reset하면 두 배우의 확정 HP·열매와 획득품을 보존하고 귀가한 뒤 다음날 탐험으로 이어간다. 직전 상태는 저장 경로 뒤의 `.reset-backup`에 보존한다. 이미 귀가/생활 중이면 비활성화한다. [상세 원인·사용법·검증](NAVIGATION_RECOVERY.md)을 따른다. 원작 방향/animation 진단은 `MysteryDungeonPet.exe --diagnostics`로 실행한다. 새 실행 시작은 `--new-run`을 명시한다.

## 개발자 갱신과 검사

제품 수정 시 개발자가 EXE도 함께 갱신한다. Windows의 MSVC/CMake/Python 환경에서는 `powershell -ExecutionPolicy Bypass -File tools/update_windows_runtime.ps1`을 실행해 루트 EXE와 `windows-runtime.json`을 생성한다. Linux 교차 빌드는 `tools/check_windows_runtime.py --refresh-from <EXE> --compiler <설명>`으로 같은 기록을 생성한다. ZIP 단계는 없다.

`python tools/check_windows_runtime.py`는 EXE·소스·사용 자산 hash 일치를 검사한다. CI의 `tools/run_windows_checks.ps1`은 MSVC 빌드와 저장소 루트 EXE를 모두 다른 작업 폴더에서 기본 실행·저장 복원한다. 실제 Windows11 GUI·잠금/절전·장기 성능 확인 여부는 최신 검증 기록을 따른다.

이동·카메라 고정31시나리오와 `--movement-trace`의 프레임CSV/BMP는 [이동 검증 안내](MOVEMENT_VALIDATION.md)를 따른다. 최신 CI에서 중간 위치·방향 전환·1/2/3배 외곽·이동 중 강제 종료/복원과 기존 생활·전투가 통과했다.

동료 검증은 `tests/companion_windows_tests.ps1`과 `pet_companion_tests`로 실행한다. `--solo`는 과거 단독 배우 snapshot 회귀용 옵션이다. 제품 기본 동작은 동료 활성화이며, 이 옵션은 이미 저장된 동료를 삭제하지 않는다.
