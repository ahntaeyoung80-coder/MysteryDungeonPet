# Windows 실행

실행 중이면 우클릭 **Exit**로 종료한다. GitHub Desktop에서 `work`를 pull한 뒤 저장소 루트의 **MysteryDungeonPet.exe**를 더블클릭한다. ZIP 생성·다운로드·압축 해제·사용자 빌드는 필요 없다. EXE와 `assets/`를 저장소 안에 함께 둔다.

기본 새 탐험은7층이다. 일반 실행은 매번 **길드의 아침 → 노공룡 입장·알람·퇴장 → 기상 인사 → 동료와 함께 퇴실 → 새 탐험**으로 시작한다. 획득품·열매·날짜·식사 횟수·최근 지형 기억은 유지하고, 이전 탐험 위치·목표·진행 중 전투는 재개하지 않는다. 재시작만으로 날짜·식사 횟수가 증가하지 않는다. 기존3층 저장도 길드에서 출발할 때7층으로 전환한다. 명시적 `--explore`는 지정 패키지·snapshot을 그대로 복원하는 개발 검증 경로다.

저장과 로그는 `%LOCALAPPDATA%\MysteryDungeonPet`에 기록한다. 저장을 삭제할 필요가 없다. `fatal invalid entity goal`이 남은 이전 저장은 NPC가 움직여 낡은 탐험 목표만 무효가 된 경우를 읽을 때 정리한다. 지도·아이템·전투 journal과 checksum 검사는 계속 적용한다. 다른 작업 폴더에서 실행해도 자산은 EXE 위치를 기준으로 읽는다.

## 현재 동작

- 기본 동료는 파이리이며 우클릭에서 변경할 수 있다. 동료가 함께 탐험한다. 평상시 가까이 추적하며, 주인공과 교전하거나 자신에게 인접한 적만 보조한다. 동료의 인식 범위는 지형상2칸이며, 주인공에게서3칸을 넘어 멀리 떨어진 전투를 새로 시작하지 않는다. 적이 지원 범위를 벗어나면 합류한다. 화면에는 주인공 HP만 표시하며 동료의 내부 HP·피해·회복은 유지한다.
- 녹색 켈리몬은 우호 NPC, 보라색 켈리몬은 적이다. 원작 MD383/sprite556과 MD384/sprite554를 각각 사용하며 저장 복원 뒤에도 관계를 유지한다.
- 전투 행동은 주인공 → 동료 → instance ID 순서의 적1·적2·적3 → 다음 라운드 주인공 순으로 처리한다. 앞선 배우의 공격·피해·기절 출력이 끝난 뒤 다음 배우가 행동한다. 평상시 이동은400ms를 함께 쓴다. 통로 양쪽의 적과 같은 라운드에 싸울 수 있고 한 적이 쓰러져도 다른 전투를 계속한다. 동료는 보조 이동 후 주인공과2칸 이내를 유지하고 다음 방의 적을 미리 사냥하지 않는다. 이동한 행동에 추가 공격하지 않는다. 어느 아군이든 기절하면 함께 귀가하고 다음날 둘 다HP5로 회복한다.
- 일반 실행의 방 탐험은 실제 제출된 화면 안에 방의 모든 바닥 타일이 완전히 표시됐는지로 판단한다. 배율1·2·3의 시야 크기에 맞춰 보이지 않은 구역을 확인하고, 이후 아이템 → 미인사 우호 NPC → 미탐색 영역/frontier → 발견된 계단을 따른다. 저체력 회복/생존 경로는 유지한다. 주인공이 멀어지면 동료는 추격을 중단하고 합류한다. 가까운 동료가 싸우고 있으면 주인공은HP1~2여도 공격하거나 적에게 접근하며 도망가지 않는다. 열매가 있으면 먼저 회복하는1턴을 쓴다. 동료가 전투 중이 아닐 때 저체력으로 안전한 목표가 없으면 실제 점유를 지키며 남은 길로 접근해 영구 도주를 피한다. 이동 불가·공격 가능이면 전투하고, 둘 다 불가하면400ms 대기 후 재평가한다. 포위·반복만으로 자동 귀가하지 않는다.
- 오랭열매는HP3 이하에서만 사용한다. 열매 사용·아이템 획득은 각각1턴을 소비한다. 우호 NPC를 목표로 찾아가며, 길을 막는 우호 NPC와 처음 만나도 인사·응답 후 동료가 들어갈 칸도 확보하며 비켜서 통과한다. 같은 NPC와의 인사는 반복하지 않는다.
- 계단 도착 →1초 fade-out → 다음 층 commit →1초 fade-in → 탐험 재개. 새 시작점과 이전 층 발밑 좌표에는 계단·아이템·배우를 배치하지 않는다. 같은 run의 원시 지형과 최근64개 전체 지형의 평행이동 중복을 거부하며 다음날도 기억을 이어간다. 개별 방의 같은 크기는 허용하고 방 영역은 서로 겹치지 않는다. 사용자가 보고한 방 중복의 정확한 장면 유형은 아직 미확인이다.
- 노란 원반은 던전의 우호 NPC에게만 보인다. 플레이어·파이리 동료·적·대화·생활 장면에는 없다.
- 공동 식사는 원래 재생 속도로6초까지 보여주고 기존7초의 마지막1초를 자른다. 푸크린 머리 위에 원작 AppleOnHead624 효과를 재생한다. 사과는 식당이 처음 보이는 귀가 fade-in부터 식사·퇴장 fade-out까지 계속 표시하고, 식사가 시작돼도 재생 시간을 초기화하지 않는다. effect.bin slot1의 animation15,13프레임/52tick과 위치 오프셋·반전을 보존해 사과가 머리 위에서 움직인다. 밤 침실이 보일 때부터 서로 바라보고, 취침 인사의 원작3프레임을4배 느리게 재생한다. 인사 장면은 최소1.6초이며 두 배우의 동작이 끝난 뒤 눕기·잠들기 animation을 한 번 재생하고 바로 fade-out/in으로 아침으로 전환한다. 긴 수면 정지 장면은 생략한다.
- 동료와 함께 취침한다. 아침 fade-in 중 두 배우의 잠든 마지막 자세 유지 → 노공룡 Walk0으로 왼쪽 방 밖에서800ms 입장 → 원작 동작3·기상 대사·화면 흔들림2초 → Walk0으로800ms 퇴장 → 두 배우 Wake14 → Nod22 인사 → 두 배우 Walk0으로 왼쪽 통로로 이동 →750ms fade-out → 새 탐험 →750ms fade-in. 주인공은 y184에서 왼쪽으로 직진하고, 동료는 주인공이 지나간 뒤 같은 직선에서 한 칸 뒤를 따른다. 출입구에 도착하면 걷기를 멈추며, 카메라는 인사 장면의 시야에서 왼쪽으로 부드럽게 따라간다. 스프라이트가 겹치면 주인공이 위에 표시된다. 원작 알람 음원은 아직 이식하지 않았다.
- 대화에는 현재 화자 한 명의 초상화만 원작 프레임에 표시하며, 문장의 감정에 따라 걱정·기쁨·슬픔·외침 등 표정이 바뀐다. 플레이어와 대화 상대는 서로 보고, NPC 대화 중 동료도 NPC를 바라본다. 명찰은 제거했다. 플레이어는 왼쪽, NPC·동료·노공룡은 오른쪽이다. 역할/배우 instance/ROM 캐릭터 ID를 분리해 캐릭터 교체 시 몸체와 초상화를 함께 선택한다.
- 탐험 중 우상단에는 `1F`처럼 층수만 하트와 같은 줄에 표시하며 화면과 함께 fade-in/out한다. 기본 뜨거운 동굴 상층7층을 마치면 원작 뜨거운 동굴 정상으로 이동하고 원작 클리어 포즈 뒤 “탐험을 성공적으로 마쳤다”를 보여준 후 귀가한다. 구형3층 테스트 던전은 공식 종료 장소가 없어 현재 맵에서 완료 문구를 표시한다. 중간 층·패배·Reset에는 성공 연출을 하지 않는다.
- 대화창은 원작 FONT/frame_b0.chr/pal의8px 테두리 타일과 왼쪽 정렬·글자 순차 출력을 사용한다. 200px 화면에184×48로 배치했으며, 한글은 Windows 맑은 고딕12px을 사용한다. 원작 한글 글꼴·전체 대사창 VM 복원을 완료한 것은 아니다.
- 피해는 각 공격의 완료 소유자와 action ID를 확인한 뒤 대상에게1회 반영한다. 저체력 도주와 적 추적 이동은 같은400ms에 표시해 매 걸음 사이 별도 휴식이 없다.
- 새 저장은 MDES11이며 MDES1~10도 읽는다. 전투 순서·화면 노출·완료 장소와 사망 대사 단계를 저장한다. 과거 동시에 시작된 공격은 완료 소유권을 지키고 끝낸 뒤 현재 순서로 전환한다. 기존 저장을 지우지 않고 합류 가능한 인접 칸에서 동료를 추가한다. 기술 선택·레벨·가방 등은 기존 범위 그대로다.

대각선 왕복은 동반 역주행 재계획으로 수정했으며, 같은 진행 상태가 반복되면 기존 다음 칸/직전 칸을 피하는 다른 방향으로 우회해 같은 층의 탐험을 계속한다. 같은 상태가 재등장하면 우회 후보를 순환하며 갈 수 있는 칸이 없으면 기다렸다가 다시 평가한다. 반복 감지는 귀가를 수행하지 않는다.

우클릭의 **내 캐릭터**와 **동료 캐릭터**에서 선택한다. 원작 주인공 후보19종, 동료 후보21종만 표시하며 나옹·먹고자는 동료 전용이다. 몸체와 감정 초상화가 함께 바뀌고 재실행해도 선택을 유지한다. 같은 종을 두 역할에 선택할 수 있다. 이동 위치·HP·획득품·날짜는 유지하며, 공격·대화·기절·클리어 연출 중 선택은 해당 연출이 끝난 뒤 적용한다.

어느 아군이 기절해도 귀가 전에 동료의 대사를 원작 대화창에 표시한다. 주인공 기절과 동료 기절의 문구·표정을 구분한다. 현재는 고정 문구이며 이후 랜덤 대사를 위한 상황/대사/화자/감정 구분이 준비되어 있다.

우클릭 메뉴는 Hide·Always on top·Scale1..3·**Reset 탐험 (귀가)**·Exit다. 탐험/전투/대화 중 Reset하면 두 배우의 확정 HP·열매와 획득품을 보존하고 귀가한 뒤 다음날 탐험으로 이어간다. 직전 상태는 저장 경로 뒤의 `.reset-backup`에 보존한다. 이미 귀가/생활 중이면 비활성화한다. [상세 원인·사용법·검증](NAVIGATION_RECOVERY.md)을 따른다. 원작 방향/animation 진단은 `MysteryDungeonPet.exe --diagnostics`로 실행한다. 새 실행 시작은 `--new-run`을 명시한다.

## 개발자 갱신과 검사

제품 수정 시 개발자가 EXE도 함께 갱신한다. Windows의 MSVC/CMake/Python 환경에서는 `powershell -ExecutionPolicy Bypass -File tools/update_windows_runtime.ps1`을 실행해 루트 EXE와 `windows-runtime.json`을 생성한다. Linux 교차 빌드는 `tools/check_windows_runtime.py --refresh-from <EXE> --compiler <설명>`으로 같은 기록을 생성한다. ZIP 단계는 없다.

`python tools/check_windows_runtime.py`는 EXE·소스·사용 자산 hash 일치를 검사한다. CI의 `tools/run_windows_checks.ps1`은 MSVC 빌드와 저장소 루트 EXE를 모두 다른 작업 폴더에서 기본 실행·길드 재시작을 검사한다. 실제 Windows11 GUI·잠금/절전·장기 성능 확인 여부는 최신 검증 기록을 따른다.

이동·카메라 고정31시나리오와 `--movement-trace`의 프레임CSV/BMP는 [이동 검증 안내](MOVEMENT_VALIDATION.md)를 따른다. 최신 CI에서 중간 위치·방향 전환·1/2/3배 외곽·이동 중 강제 종료/복원과 기존 생활·전투가 통과했다.

동료 검증은 `tests/companion_windows_tests.ps1`과 `pet_companion_tests`로 실행한다. `--solo`는 과거 단독 배우 snapshot 회귀용 옵션이다. 제품 기본 동작은 동료 활성화이며, 이 옵션은 이미 저장된 동료를 삭제하지 않는다.
