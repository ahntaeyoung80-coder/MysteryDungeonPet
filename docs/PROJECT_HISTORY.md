## 최신 요구와 과거 규칙의 관계

- 최신 동료 전투/도주/복귀 지시는 과거의 항상 반경1칸 강제·같은 방 지원·단일 조우 전투보다 우선한다.
- 자동 귀가 복구와 목표 상실 시 자동 귀가를 제거했다. 공격 가능이면 전투, 이동/공격 모두 불가하면400ms 대기·재평가한다. 명시 Reset·패배·정상 클리어는 기존 생활 루프를 따른다.
- 기존 원시 terrain hash는 위치가 달라진 동일 지형을 허용했다. 실제 C++ 실패를 고정한 뒤 최근64개 정규화 전체 지형을 층/다음날에 전달한다. 개별 방 크기의 유사성·카메라 재방문·사용자 미확보 장면을 모두 해결했다고 확대하지 않는다.
- MDES8·기본7층이 새 실행 기준이다. MDES1~7 읽기를 유지하고 기존3층 저장은 현재 run을 보존한 뒤 다음날부터7층으로 전환한다. 명시적3층 실행은 그대로 유지한다.
- 과거 검증 성공은 해당 커밋·명세·환경에 한정한다. 새 요구는 별도 회귀와 실제 Windows 표시/복원 검증이 필요하다.
