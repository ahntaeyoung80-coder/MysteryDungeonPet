## 최신 요구와 과거 규칙의 관계

- 최신 동료 전투/도주/복귀 지시는 과거의 항상 반경1칸 강제·같은 방 지원·단일 조우 전투보다 우선한다.
- 자동 귀가 복구는 폐기됐다. 그러나 목표 상실 시 귀가 경로가 별도로 남아 있으므로 포위 문제를 해결했다고 볼 수 없다.
- 기존 방 검사는 같은 run의 전체 terrain 완전 중복과 방 사각형 겹침을 다룬다. 개별 방의 유사성·다음날 반복·카메라 재방문 보고를 모두 해결한 검사가 아니다.
- MDES7와 기존3층 기본 탐험이 현재 실행 기준이다.7층 적용 때 저장을 지우는 방식으로 호환 문제를 넘기지 않는다.
- 과거 검증 성공은 해당 커밋·명세·환경에 한정한다. 새 요구는 별도 회귀와 실제 Windows 표시/복원 검증이 필요하다.
