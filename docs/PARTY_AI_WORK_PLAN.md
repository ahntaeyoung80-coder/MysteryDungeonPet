## 최소 회귀·판정

1. 빈 방의 같은 행/열 목표는 장애물이 없을 때 직선으로 진행한다. 벽·점유 회피는 합법 최단 경로를 사용한다.
2. HP5/HP1의 action/start/deadline·보간·Wait·전투 완료를 구분해 측정한다. HP1 지연 원인은 측정 전 확정하지 않는다.
3. HP1 포위 시 자동 귀가0회. 이동 불가·공격 가능이면 전투, 둘 다 불가면 대기/재평가한다.
4. 통로 `적A–동료–주인공–적B`에서 양쪽 아군과 적이 각각 라운드 행동권을 사용한다. 한 적이 죽어도 반대쪽 행동이 멈추지 않는다.
5. 주인공 도주 중 동료는 진행 중 전투를 마무리하고 복귀한다. 평상시 가까이 추적하되 전투 중1칸 밖 상태를 합법적으로 저장/복원한다.
6. 매행동·피해 확정/완료 사이 중단·복원에서 피해/소비/행동이 중복되거나 누락되지 않는다. 기존 명중/피해와 이동 후 추가 공격 금지를 보존한다.
7. 동료 HP는 내부 유지·화면 숨김. 녹색 우호/보라색 적을 실제 픽셀·관계·방향·저장 복원으로 검증한다.
8. 기본1~7층과7층 정상 클리어, 기존3층 저장의 출처별 복원·진행 유지를 검증한다. 기존 저장 삭제를 이행 방법으로 사용하지 않는다.
9. 방 중복을 전체 terrain·개별 방 모양/배치·다음날/새 run·카메라 재방문으로 구분하고 재현된 유형을 해결한다.
10. 기존 생활·수동 Reset·이동/카메라·원본 자산 회귀를 관련 변경에 맞춰 재사용한다. 이전 CI 성공으로 새 요구를 통과 처리하지 않는다.
