## 실행과 수정 위치

실행 중인 앱을 Exit로 종료하고 `work`를 pull한 뒤 루트 `MysteryDungeonPet.exe`를 실행한다. 기존 저장을 삭제하거나 새 실행 옵션을 사용할 필요가 없다.

- 일상·사건 대사: `assets/original/gameplay/dialogue/catalogue.json`. 수정 후 `python -m tools.compile_dialogue_catalogue`로 MDLC를 갱신한다. 긴 문장은 2줄 페이지로 나뉘며, 화자 계약을 바꾸면 compiler와 runtime을 함께 확인한다.
- 이름·아이템 반응: `src/core/item_names.inc`, `src/core/gameplay_notice.cpp`.
- 원정의 추가 회복 공급: `src/core/exploration.cpp`의 `enterFloor`. 원본 출현 가중치를 덮어쓰지 않는다.
- 상시 패널·대기 초상화·상태 문구: `src/core/gameplay_scene.cpp`, `src/windows/main.cpp`의 `currentPortrait`, `displayText`, `updateDesktopState`.
- 패널: 화면 x8~191/y144~191, 본문 x16~183/y152~183, 초상화 프레임 y88~143, 그림 y96~135. 글자·배경·불투명도 보정 영역은 함께 변경한다.

PC 입력 상태 표시는 이번 상시 UI 실험 범위다. 사용 중인 앱을 분류하거나 PC 활동으로 생활 정책을 변경하는 전체 기능은 포함하지 않는다. 실제 Windows 11의 잠금·절전·DPI·장기 성능 검증은 별도로 남는다.
